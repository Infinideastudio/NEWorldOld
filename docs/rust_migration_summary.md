# NEWorld Rust 迁移方案 - 执行摘要

## 📊 项目现状

- **代码量**: ~12,000 行 C++23 代码
- **文件数**: 65+ 源文件
- **架构**: 模块化设计 (C++20 模块)
- **项目类型**: 体素游戏引擎 (类 Minecraft)

## 🎯 迁移收益

| 维度 | 预期提升 |
|------|---------|
| **内存安全** | 消除 90%+ 内存 bug |
| **并发安全** | 编译期数据竞争检查 |
| **性能** | 5-15% 性能提升 |
| **开发效率** | 更快的迭代周期 |

## ⏱️ 时间估算

- **最小可行方案 (MVP)**: 3-4 个月
  - Phase 1: 数学库 (2-3 周)
  - Phase 3: 方块/区块系统 (3-4 周)
  - Phase 4: 地形生成 (2-3 周)
  - Phase 7: 世界持久化 (3-4 周)

- **完整迁移**: 13-14 个月 (1 名全职开发者)
  - 14 个阶段
  - 覆盖所有模块

## 🔧 核心技术映射

| C++ 依赖 | Rust 替代 |
|---------|----------|
| GLFW3 | `winit` + `glutin` |
| OpenGL/GLAD | `gl` crate |
| FreeType | `freetype-rs` |
| LevelDB | `leveldb` / `rusty-leveldb` |
| spdlog | `tracing` |
| CMake | `Cargo` |

**推荐新增**:
- `glam` - SIMD 优化数学库
- `rayon` - 数据并行
- `tokio` - 异步运行时
- `noise` - 地形噪声生成

## 📋 迁移策略

**渐进式迁移** (推荐):
1. 建立 Rust 子项目 (`rust/` 目录)
2. CMake 集成 Cargo 构建
3. 通过 FFI 边界逐模块迁移
4. 保持项目持续可用

## 🎓 学习曲线

- **Rust 基础**: 2-4 周
- **所有权系统**: 2-3 周实践
- **异步编程**: 1-2 周
- **unsafe/FFI**: 1 周

## 🚀 快速开始

### MVP 优先级模块

1. ✅ **数学库** - 简单、高学习价值
2. ✅ **方块/区块** - 高内存安全收益
3. ✅ **地形生成** - 易并行优化
4. ✅ **世界存储** - 数据安全关键

### 第一步

```bash
# 1. 安装 Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# 2. 创建 Rust 子项目
mkdir rust
cd rust
cargo init --lib

# 3. 配置基础依赖
cargo add glam  # 数学库
```

## ⚠️ 主要风险

| 风险 | 缓解措施 |
|------|---------|
| 学习曲线 | 提前培训、逐步迁移 |
| FFI 开销 | 基准测试、优化边界 |
| UI 复杂度 | 考虑使用 `egui` |
| 时间超支 | 预留缓冲、可暂停 |

## 💡 替代方案

**考虑使用 Bevy 引擎**:
- Rust 原生游戏引擎
- ECS 架构
- 完整的渲染/UI/音频支持
- 活跃社区

需要重新设计架构，但长期收益更大。
